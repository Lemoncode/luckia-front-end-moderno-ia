## 04-framework-react · Cuatro sesiones de dos horas

Partimos de una lista hecha con JavaScript y terminamos con una aplicación que permite consultar, dar de alta y editar personas. Cada tema contiene su explicación y una carpeta `demos/`; cada demo se instala de forma independiente.

| Sesión | Tema | Contenido |
| --- | --- | --- |
| 1 | [De JavaScript a React](./04-framework-react/01-de-javascript-a-react/de-javascript-a-react.md) | DOM, componentes, props, estado y eventos |
| 2 | [Hooks](./04-framework-react/02-hooks/hooks.md) | Estado, efectos, custom hooks, refs, memorización y React Compiler |
| 3 | [Aplicación con React](./04-framework-react/03-aplicacion/aplicacion-con-react.md) | Rutas, lista y detalle, componentes y formularios |
| 4 | [Arquitectura](./04-framework-react/04-arquitectura/arquitectura.md) | Directorio y edición en dos pods, contratos compartidos y persistencia local |
