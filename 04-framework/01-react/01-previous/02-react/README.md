# La misma lista con React

Segunda demostración de [01 · Por qué React](../README.md). Volvemos a construir la misma pantalla, ahora con componentes y estado. La comparación entre `src/app.tsx` y el `main.ts` de `01-vanilla` nos permite explicar qué trabajo pasa a hacer React.

Con las dependencias instaladas desde `01-react`:

```bash
npm start
```

El proyecto contiene la versión con añadir personas, input controlado, total derivado y claves estables. Cerramos la explicación desarrollando Eliminar en directo: el botón vive en la fila y avisa mediante una prop al componente que guarda la lista. Esa ampliación está desarrollada en la guía de la sesión.

```bash
npm run build
```
