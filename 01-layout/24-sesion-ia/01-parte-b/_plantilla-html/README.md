# Plantilla HTML + Tailwind v4 + Vite

Base para una pantalla nueva. Para empezar un proyecto:

```bash
cp -R _plantilla-html 04-mi-proyecto
cd 04-mi-proyecto
npm install            # usa el package-lock.json: evita el error ERESOLVE
npm i @fontsource-variable/<fuente>   # las fuentes que pida el brief
```

Cambia `name` en `package.json` y `<title>` en `index.html`.
